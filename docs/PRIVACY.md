# 隐私与本地数据

## 数据流

接收助手在本机打开用户选择的 SDR，将 IQ 采样在内存中转换成频谱与可选的音频。网页通过本机 HTTP 接口读取频谱及状态；FM 声音直接输出到本机声卡，不通过网页上传。

HTTP 服务只绑定 `127.0.0.1`，默认端口 `8766`。项目没有云端接收服务、遥测、广告分析、账号系统或自动上传功能。不采集麦克风或系统播放声音，也不提供 IQ/广播录音功能。不要把本机接口反向代理到公网或局域网。

安装 Python 依赖、获取设备驱动、访问 GitHub 或使用 Steam/Wallpaper Engine 可能联网；这些外部软件的网络与隐私行为不由本项目控制。“本机接收”不表示运行环境里的所有软件均不联网。第三方 Soapy 设备模块也可能连接用户配置的网络设备。

## 会留下什么

| 数据 | 用途 | 处理方式 |
| --- | --- | --- |
| 频谱历史、IQ/音频缓冲 | 实时显示和播放 | 内存中有限缓冲，不作为录音写盘 |
| 收藏名称与频率、上次频率、音量 | 下次启动恢复偏好 | 本机 JSON 文件，不自动同步 |
| 运行/错误日志 | 排查接收或播放故障 | 本地保存，可能含频率、设备错误及文件路径 |
| 壁纸切换会话记录（使用该功能时） | 保留/恢复用户选择 | 本地保存，可能含 Wallpaper Engine 工程路径 |
| 控制会话令牌 | 限制本机控制请求 | 运行时生成，不应公开分享 |

数据目录与源码分离。设置 `INVISIBLE_TERRAIN_DATA_DIR` 可指定专用目录；未设置时，Windows 使用 `%LOCALAPPDATA%\InvisibleTerrain`，其他系统使用 `$XDG_STATE_HOME/invisible-terrain`，若未设置 `XDG_STATE_HOME` 则使用 `~/.local/state/invisible-terrain`。不要把共享或公开同步目录设为数据目录。

此仓库不包含任何用户的收藏、配置、日志、会话记录或驱动二进制。忽略规则降低误提交风险，但不能代替人工检查。

收藏可在控制台删除。需要备份或手动清空本地文件时，先停止接收并退出助手，避免运行中的写入覆盖修改。不要在程序运行时手工编辑收藏 JSON；损坏文件可能需要由用户备份后修复。

## 本机接口的边界

控制请求检查请求来源和会话令牌；Wallpaper Engine 的本地文件页面只读，不获得控制令牌或收藏名称。频谱状态仍是可被本机页面读取的展示数据。该接口不是为多用户强隔离设计的，也不能抵御已经能在同一电脑上运行的恶意程序。

声音每次启动默认关闭；记住音量不等于自动播放。除非用户主动选择开机接收，否则启动助手不应被理解为授权任意外部程序操作 SDR。项目没有发射功能。

## 报告问题前

只提交定位问题所需的最小片段，并移除设备序列号、个人目录、收藏名称、令牌、网络设备地址及其他个人信息。不要提交整个运行目录、桌面截图中的私人内容、原始 IQ 或广播录音。如果问题涉及敏感信息，先说明问题类型，不要将敏感材料发布在公开 issue 中。
